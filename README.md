# Power With | BCG Week 5

Student reading companion for the Berkeley Changemaker Gateway, Fall 2026. Adapts the instructor-supplied *Frames for Changemaking* slides with source attribution. Links to Brené Brown's original handout rather than reproducing it.

Static GitHub Pages site. Publish index.html, style.css, and reading.js at repository root; deploy from the main branch. No build step, external fonts, analytics, student data collection, or third-party dependencies. The small reading.js script updates the reading-progress line and current navigation section; it stores nothing. All required content and optional questions remain available without scripting through native HTML details controls.

The journal remains the place students write and submit their work. No student submissions, instructor analysis, private correspondence, or credentials belong in this repository.
